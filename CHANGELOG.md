# Changelog

All notable changes to OralCare are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-06

### Added

- Patient risk assessment, red-flag safety override, guided self-examination,
  lesion recording, follow-up reminders, and consent controls.
- Clinician queue, assessment, outcome capture, and pilot validation metrics.
- Firebase Authentication and Cloud Firestore data sharing between patient and
  clinician devices.
- Firestore security rules, Flutter CI, Dependabot, and public setup guidance.

### Safety

- Marked risk weights and thresholds as provisional pilot values.
- Added explicit non-diagnostic patient guidance and documented production
  security prerequisites.
